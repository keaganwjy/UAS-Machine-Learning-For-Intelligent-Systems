# PENGGUNAAN COMPUTER VISION UNTUK GAME SPACE INVADERS

Anggota Kelompok:

- Bryan Harijanto (36240045)

Proyek yang kami kerjakan ini sebagai bahan untuk ujian akhir semester mata kuliah Machine Learning For Intelligence Systems. Pada proyek ini kami menggunakan tema game space invaders yang diimplementasikan menggunakan computer vision

Langkah-langkah untuk memulai game:
1. Silahkan jalankan file space_invaders.py
2. Setelah file terbuka, klik mulai game untuk masuk ke halaman permainan
3. Untuk menggerakkan karakter silahkan kepalkan tangan dan arahkan ke kamera, lalu gerakan ke arah kanan atau kiri untuk mengarahkan karakter
4. Untuk menembak musuh silahkan berikan tampilan jari telunjuk anda
5. Saat ingin berhenti sejenak, kalian bisa tekan tombol "P"
6. Lalu terdapat jumlah nyawa sebanyak 3 jika terkena serangan dari musuh, maka nyawa akan berkurang 1. Jika nyawa sudah 0 atau habis maka game akan berakhir, begitu juga saat musuh sudah sampai bawah maka permainan berakhir.
7. Saat permainan berakhir kalian bisa pencet tombol menu untuk kembali ke halaman menu atau halaman utama, tetapi jika kalian ingin selesai bermain game maka kalian bisa tekan tombol keluar.
